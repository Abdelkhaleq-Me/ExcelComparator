# 📊 المطابق الذكي لملفات إكسيل (Excel Comparator Pro)

تطبيق احترافي ذكي وعالي الأداء لمقارنة ملفات Excel، مبني باستخدام لغة **Python** وواجهة **PySide6 (Qt)**. يتميز التطبيق بقدرته العالية على معالجة البيانات بسرعة فائقة وتوليد تقارير إكسيل تفصيلية ومنسقة باحترافية.

---

## ✨ المميزات الرئيسية

### 🚀 1. أداء خارق ومعالجة ذكية (Ultra Performance)
* **المعالجة المتجهة (Vectorized Processing):** يعتمد على مكتبة `pandas` لتسريع عمليات المقارنة بمعدل **42 ضعفاً** مقارنة بالحلقات التقليدية.
* **الذاكرة المؤقتة الذكية (`lru_cache`):** تسريع معالجة وتطبيع القيم المتكررة بمعدل **120 ضعفاً**.
* **الوصول السريع للملفات:** دمج استعلامات المعلومات واكتشاف العناوين في تمريرة واحدة للملف باستخدام وضع القراءة فقط (`read_only`) بمكتبة `openpyxl` لتسريع التحميل بمعدل **30 ضعفاً**.
* **كفاءة الذاكرة في التقارير:** استخدام الأنماط المشتركة (`NamedStyles`) لمنع استهلاك الذاكرة وتخفيف حجم التقرير النهائي.

### 🧠 2. تنظيف وتطبيع ذكي للبيانات (Smart Normalization)
* **تجاهل التشكيل والتطويل:** تجاهل الحركات التشكيلية العربية بالكامل (الفتحة، الضمة، الكسرة، السكون، الشدة، التنوين) والتطويل/الكشيدة لتفادي الاختلافات الوهمية (مثل تطابق "أوُل" مع "أول").
* **تنظيف المعرفات (Key Columns):** إزالة الأصفار البادئة غير المؤثرة في المعرفات البريدية أو الهويات بشكل تلقائي.
* **التوافق الرقمي والزمني:** التعرف الذكي على التواريخ المكتوبة بصيغ مختلفة وتنسيقها بشكل موحد قبل المقارنة، والتعامل الذكي مع الأرقام العشرية والصحيحة.

### 🎨 3. واجهة مستخدم عصرية وسلسة (Sleek GUI)
* **دليل معالجة خطوة بخطوة (Wizard Layout):** واجهة مقسمة إلى خطوات منظمة تسهل عملية الإعداد والمقارنة.
* **التعرف التلقائي على العناوين:** خوارزمية ذكية لاكتشاف صف العناوين (Header Row) تلقائياً بمجرد اختيار ورقة العمل.
* **المطابقة التلقائية للأعمدة:** ميزة المطابقة التلقائية للأعمدة المتطابقة بالأسماء لتوفير وقت الإدخال اليدوي.
* **مرونة كاملة في الأبعاد:** واجهة مرنة تدعم التمرير التلقائي (Scrollable) لضمان سهولة الاستخدام على الشاشات الصغيرة وأجهزة المحمول بدقة منخفضة دون إخفاء أي أزرار.
* **إحصائيات تفاعلية فورية:** عرض ملخص رقمي ملون ومنسق للنتائج فور انتهاء المقارنة مباشرة داخل نافذة البرنامج.
* **نوافذ تنبيه منسقة:** تم تخصيص وتنسيق نوافذ التنبيهات المنبثقة بالكامل لتتماشى مع الهوية البصرية للبرنامج.

### 📝 4. تقارير تفصيلية فاخرة (Excel Reports)
ينتج التطبيق تقريراً تفاعلياً ملوناً ومنسقاً يحتوي على:
1. **الملخص التنفيذي:** تقرير بياني يعرض نسب وأرقام الأسطر المتطابقة والمختلفة والفريدة مع نسب مئوية دقيقة لكل عمود.
2. **تفاصيل الاختلافات:** جدول تفصيلي يوضح المعرف والاسم مع تحديد الخلايا المختلفة وتلوين القيم القديمة والجديدة بوضوح تام.
3. **الأسطر المتطابقة:** قائمة بكافة الأسطر التي تطابقت بياناتها بنسبة 100%.
4. **الأسطر الفريدة:** أوراق عمل منفصلة توضح الأسطر المتوفرة في أحد الملفين فقط.

## 🛠️ متطلبات التشغيل والتثبيت

تأكد من تثبيت لغة **Python 3.8+**، ثم قم بتثبيت المكتبات المطلوبة عبر تنفيذ الأمر التالي في مجلد المشروع:

```bash
pip install -r requirements.txt
```

### المكتبات الأساسية المستخدمة:
* `PySide6` (الواجهة الرسومية)
* `pandas` (معالجة البيانات الفائقة)
* `openpyxl` (قراءة وكتابة ملفات إكسيل وتصميم التقارير)
* `qtawesome` (حزمة الأيقونات الحديثة)

---

## 🚀 طريقة التشغيل واستخدام التطبيق

تشغيل التطبيق مباشرة عن طريق كتابة:

```bash
python main.py
```

### خطوات الاستخدام:
1. **الخطوة 1:** اختر الملف المرجعي الأول، وحدد ورقة العمل، ثم حدد العمود المفتاح (مثل رقم التعريف أو الحساب).
2. **الخطوة 2:** اختر الملف المقارن الثاني، وحدد ورقة العمل والعمود المفتاح المماثل.
3. **الخطوة 3:** اختر الأعمدة المتقابلة التي ترغب في مقارنتها (يمكنك استخدام **المطابقة التلقائية**).
4. **اضغطي على "إجراء المقارنة":** سيتم نقلك تلقائياً لصفحة النتائج، واختيار مكان حفظ ملف التقرير، لتظهر لك الإحصائيات الفورية ويصبح زر **فتح ملف التقرير** متاحاً في الأسفل.
